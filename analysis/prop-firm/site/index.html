Every strategy combination is listed. Filter it the same way as the Strategy page, then run the ones you want. The Strategy column shows a star when that run is a favourite there; Strategy favourites only hides the rest. A star you set on this page is a separate prop favourite, still stored with this CSV. If the strategy page has already saved that run’s trade CSV, the analysis uses it and does not rebuild the backtest. If the CSV is missing, Run exports it first, then replays the 2-step account.

  • $5,000 account, fee $22. One account for each New York weekday, so five accounts can be open at once. A Tuesday loss does not touch Monday’s account. A blown weekday is replaced on its next trade. Prop firm 2 instead buys one account and trades it every day.
  • Phase 1 needs $400 and 3 days of at least $25. Phase 2 needs $250 and 3 such days. Funded profit is paid at 80% once it is at least $20, with 3 winning days and 10 weekdays after the first funded trade. The balance returns to $5,000.
  • To funded is the median calendar days to the first funded account across the weekdays that reached it. Each weekday’s count runs from that weekday’s first trade and includes accounts that blew before the pass. Funded wds is how many of the five weekdays reached funded at least once.
  • Funded 1st, Blown 1st, Funded % and Earliest restart every weekday account on the 1st of each month from January 2020. A weekday only takes its own later trades, and that account stops at its first funded or blown result. It does not buy a replacement. Funded % ignores weekdays still open at the end of the file. Open a row to see Monday through Friday for each month.
  • Touching $4,600, or that day’s 4% line, blows the account. The open loss uses the trade’s worst adverse excursion from the CSV.
  • A 50-point stop is 0.10 lot. A 100-point stop is 0.05 lot. On US100 that is $2 and $1 per index point, so both stops are $100. The spread is already inside the strategy trade CSV.
  • Cash open is Skip 09:30 or Include 09:30. On US100 the stored New York RTH id skips that bar. The same id ending in _keep includes it and has no result until you run it. London, New York and All already include the minute.
  • NY open is Skip or Include 08:30-08:32, and only for the New York session. The stored id includes 08:30 and 08:31. The same id ending in _skip drops those two New York minutes. 08:32 stays. RTH, London and All are unchanged.
  • Results are stored under analysis/prop-firm/results/<csv stem>/prop.json. Strategy files are not modified except when a missing trade CSV has to be exported.
